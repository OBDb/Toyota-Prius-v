# Toyota Prius v

This repository contains signal set configurations for the Toyota Prius v, organized by model year and version. The files are structured to allow for easy differentiation between model generations and other vehicle parameters, ensuring accurate signal mapping for each version of the Toyota Prius v.

The Toyota Prius v (also known as Prius α in Japan and Prius+ in Europe) is a compact MPV that expanded the Prius family with a more practical wagon-like body style offering substantially increased cargo capacity and interior space. Produced from 2011 to 2021, the Prius v was powered by Toyota's Hybrid Synergy Drive system combining a 1.8-liter Atkinson-cycle gasoline engine with electric motors.
